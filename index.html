A touchless drawing system using OpenCV and MediaPipe with real-time 21-point hand tracking and character recognition.

  • Implemented custom line-smoothing and noise filtering algorithms to reduce hand tremors and improve drawing accuracy.

Vehicle Detection and Counting System

A web-based traffic video processing application built with YOLOv8n and Flask to classify vehicles and automate counting.

  • Utilized lightweight YOLOv8n with COCO-trained weights to detect and classify multiple vehicle categories (cars, buses, trucks, motorcycles).
  • Generated annotated output videos displaying bounding boxes, class labels, and configurable confidence thresholds.
  • Built an interactive Flask web dashboard allowing users to upload surveillance videos and view real-time vehicle counts.
