SkyWrite (Air Canvas)

Touchless Real-Time Gesture Drawing & Character Recognition System

A touchless digital canvas application built using MediaPipe and OpenCV for high-fidelity 21-point 3D hand tracking on standard RGB webcam feeds. Integrates a custom Convolutional Neural Network (CNN) trained on the EMNIST dataset to classify touchlessly drawn letters and digits in real time.

Zero-Hardware 21-Point Tracking: Real-time hand landmark tracking at interactive 60fps without external sensors.
87% Character Recognition: Custom CNN trained on EMNIST achieving 87% accuracy across drawn characters.
Jitter-Reduction Algorithms: Formulated custom mathematical line smoothing to filter tremor noise on canvas strokes.
Python OpenCV MediaPipe TensorFlow CNN EMNIST

Automated Intelligent Traffic Surveillance Pipeline & Video Stream Processing

An automated intelligent traffic surveillance pipeline that processes uploaded traffic video footage using the lightweight YOLOv8n model with COCO-trained weights. Automates multi-class vehicle classification and counting within an interactive Flask web application.

High-Speed Multi-Class Inference: Classifies cars, buses, trucks, and motorcycles at high throughput.
Annotated Video Synthesis: Renders bounding boxes, class labels, and configurable confidence thresholds.
